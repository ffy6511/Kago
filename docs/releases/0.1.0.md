Kago equips each project with its own set of Agent Skills from a Git-tracked manifest. Use it in Magpie or through the `kago` CLI, with a preview before deployment and ownership checks that protect local files.

### Feat

- **Project skill sets**: Select skills from categorized sources, choose project defaults and override target agents per skill. Shared agent directories are deduplicated.
- **Preview and sync**: Review changes, then save the manifest and deploy relative links or copies. Repeated synchronization is idempotent, and locally modified or unmanaged files are protected.
- **Workspace management**: Inspect existing skills, read and edit their documents, and confirm deletion of individual links or folders.

### Install

```sh
magpie plugin add @jhzhuo/kago
```

For CLI-only use:

```sh
npm install --global @jhzhuo/kago
```

## 中文

Kago 通过纳入 Git 的清单，为每个项目配好所需的 Agent Skills。可在 Magpie 页面或 `kago` CLI 中使用，部署前预览变更，并通过所有权检查保护本地文件。

### 新功能

- **项目技能组合**：从分类来源选择技能，设置项目默认 agent，也可为单个技能覆盖。共享 agent 目录自动去重。
- **预览与同步**：检查变更后保存清单，部署相对软链或复制。重复同步保持幂等，本地修改和未托管文件受到保护。
- **工作区管理**：查看已有技能，阅读和编辑文档，确认后删除指定软链或目录。
