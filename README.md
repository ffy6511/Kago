# Magpie Skill Workspaces

A distributable Magpie plugin for categorized skill sources and Git-tracked project skill manifests. Development follows [the spec](docs/spec.md); see [integration boundaries](docs/integration.md).

```sh
bun install
magpie plugin add /absolute/path/to/magpie-skill-workspaces
```

Tested with Magpie 0.1.3037. No custom Magpie build required.
